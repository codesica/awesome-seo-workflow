# Synthetic template exercise / 合成模板练习

输入和输出是为本项目编写的虚构教学材料，不是客户网站、真实搜索需求或商业成功记录。example.com 不代表已抓取的目标站点。

本例贯穿四个 Skill：一个读者问题 → 页面 brief → 本地 noindex 阻塞 → 无基线数据决策。四份输出只演示交接结构，不表示第 03 内容制作或第 05 推广阶段已经执行。

- 机会：没有搜索量来源，必须保留 null / unknown。
- brief：生成了提纲但核心证据待补，不会自动写作/发布。
- 发布检查：七项都覆盖；本地 noindex 明确冲突，线上 HTTP 与内链验证未知。
- 衡量：6 / 200 = 0.03。没有基线，点击变化与相对提升必须为 null。

运行 `python qa/validate.py` 验证字段、路径与几个关键数据不变量。该验证不调用真实搜索服务，不运行浏览器，不验证真实 Skill 执行能力或线上效果。
