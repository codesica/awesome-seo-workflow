# 研究判据
意图标签可使用 informational / commercial-investigation / transactional / navigational / local / mixed，但必须由结果与用户任务支撑，不能只凭关键词词面。建议“为什么用户搜索这个”时标明 inference。

比较矩阵应检查：目标受众、任务完成方式、覆盖范围、原创证据、可验证来源、更新时间依据、易读性和操作阻力。数据/作者/更新时间未显示只表示未观察到，不等于页面没有这些信息。

Google 结果会受语言、地区、设备及其他上下文影响；关闭个性化也不消除地区等因素。单次浏览器观察不能代表所有用户或排名历史。搜索工具/API 返回列表也不应冒充浏览器当前屏幕。

site: 可帮助发现页面样本，但不保证返回全部已索引页面，无关键词时也不代表常规排名。判断自己页面的索引情况优先用获授权 Search Console URL Inspection；不能检查他人私有 property。

竞品主张按来源区分：页面自述 / 页面引用可核验资料 / 研究者推断。对流量、收入、效果等不可见数据保持 unknown。转化按钮存在不等于转化率高；长内容不等于质量高。
