# Synthetic template exercise

The inputs and outputs are fictional teaching materials created for this project. They are not a client website, real search-demand evidence or a business-success record. example.com is not a target that has been crawled.

This example spans four skills: one reader question → page brief → local noindex blocker → data decision without a baseline. The four outputs demonstrate only the handoff structure; they do not indicate that stage 03 (content production) or stage 05 (promotion) has been executed.

- Opportunity: there is no search-volume source, so null / unknown must be retained.
- Brief: an outline is provided, but core evidence is still needed; writing/publication is not automatic.
- Publish audit: all seven checks are covered; local noindex is an explicit conflict, while live HTTP and internal-link verification remain unknown.
- Measurement: 6 / 200 = 0.03. Without a baseline, click change and relative improvement must be null.

Run `python qa/validate.py` to check fields, paths and several key data invariants. The validation does not call a real search service, run a browser, establish real skill-execution capability or verify live outcomes.
