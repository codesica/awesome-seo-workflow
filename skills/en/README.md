# English original Skills

[Project README](../../README.md) · [Usage](../../USAGE.md) · [中文原版](../browser/)

Choose one of the three browser Skills in `browser/` or four workflow Skills in `workflow/`. Each named folder contains its own `SKILL.md` and required relative resources. Its `name`, machine schema, scope, and source-reviewed / live-site NOT_RUN boundaries match the Chinese original. Install only one language of each same-named Skill.

The [language manifest](../locales.json) maps all seven names to English/Chinese source folders, raw entrypoints, and current download URLs. Download complete English packages from https://skills.yangluotong.top/en/skills/ rather than copying only a `SKILL.md` file. Chinese originals remain under `skills/browser/` and `skills/workflow/`.

English browser references include full output-field explanations. Workflow entrypoints include their complete inline templates and interpretation/acceptance instructions, and `workflow/examples/` supplies translated synthetic handoff examples. Machine fields and status values stay English. Original Chinese HTML fixtures and optional `README.zh.md` companions in the publication audit are preserved raw evidence, not untranslated execution instructions.

Translation checks establish local language coverage and compatibility only; no live Skill, private account, indexing, ranking, or growth test was performed. The original three linked third-party projects are separate and are not included in these seven packages.
