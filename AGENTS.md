# Project instructions

Keep this project bilingual. Preserve corresponding routes, deep links, original evidence, complete Skill instructions and downloadable resources.

Before changing the relevant area, read its project standard:

- [Image generation](docs/standards/image-generation.md)
- [UI](docs/standards/ui.md)
- [Visual interaction](docs/standards/visual-interaction.md)
- [Content](docs/standards/content-standard.md)
- [Research](docs/standards/research-standard.md)

Use the existing cold white page background, dark green text and restrained lime accents. Use actual generated editorial illustrations; no decorative emoji or icon piles. Functional native controls remain accessible.

Run `npm run check` locally before delivery. `npm run check:standards` checks the existing build and metadata only. Templates are not completed research. Keep manual review, real novice tests and business outcomes separate from automatic checks; unperformed work remains `NOT_RUN`.

This repository has no GitHub Actions workflows. Do not add, enable or trigger Actions unless the user explicitly requests it for that task. Do not change account permissions, credentials, domains or unrelated worktrees as part of UI work.
