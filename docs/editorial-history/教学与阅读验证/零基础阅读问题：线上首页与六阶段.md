# 零基础阅读问题：线上首页与六阶段

已实际读取 https://skills.yangluotong.top/zh/ 和六个 /zh/stages/ 页面，全部200。以下是编辑审查，不是真实用户测试。

1. 首页的“SEO、Agent、流程、产物”先于用途。读者不知道谁在搜索、为何要做一页、搜索结果与自己网站有什么关系；右侧canonical冲突是第4阶段技术问题，作为第一次示例门槛高。
2. 第1阶段直接要求5–10问题、3候选搜索研究、机会卡；把需求证据、搜索量、意图、长期查询分布放在实际小练习前。应先一个可在自己文档写好的四行草稿，再逐步验证假设。
3. 第2阶段9个先修概念（含canonical/hreflang）、长简报字段盖过“这页帮谁做什么”；缺一个填好的短页面计划，也没帮助无网站读者理解页面是什么。
4. 第3阶段要求来源、title/description、素材权利与完整内容包；没有展示前一步四行如何长成可阅读/可使用的页面。渲染过早讲解。
5. 第4阶段一次投放robots、noindex、响应头、canonical、sitemap、hreflang、Search Console、HTTP；普通人无法判断或操作。先打开最终网址、看正文图片、点主按钮，技术项折叠给维护者/Agent；未检查仍必须写未知。
6. 第5阶段先谈站内发现、外链、UTM与渠道规则，缺一个“在哪里有相关的人、如何一句话分享、没发出去怎么办”的假设样稿。制作和推广不能删，发送权限与草稿/已发边界保留。
7. 第6阶段尚无数据的读者仍要读CTR、平均位置、筛选、基线、转化。先一个问题观察和真实反馈，再有账号时引入数据；缺失不是0，相关不是因果。
8. 全站模板是空白JSON；对小白不是成品示范。保留机器下载，但先展示一份填好的教学例子和自然语言小练习；明确只在自己的文档做、不用上传、不需账号起步。

统一落地原则：同一明确假设的免费5分钟冥想计时页贯穿；每阶段普通人问题→小例子→一个动作→填好的示例产物→能自判的完成标准。技术细节折叠，术语随用随释，Skills在理解后。六阶段IDs/职责、原教程和7个完整Skills保留。

阅读验收五问：为谁做？先做什么？需账号吗？成品长什么样？完成怎么判断？不能把交给Agent或AI自述当新手完成/真实用户测试。
