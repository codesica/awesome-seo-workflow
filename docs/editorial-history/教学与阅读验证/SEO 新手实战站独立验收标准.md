# SEO 新手实战站独立验收标准

冻结时间：2026-10-10 11:53 UTC。此标准先于实现及内容评审写定，不因验收结果降低要求。状态只能依据可复核证据判断；未执行的检查标为待验证，不能算通过。

## 核心用户旅程（发布阻断项）
1. 首次访问首页，无 SEO 背景的用户能根据明确目标选择一个任务，知道预期产物、所需输入、工具/费用前提与大致操作范围。
2. 从任务进入完整英文教程；术语首次出现有解释，步骤按执行顺序，能知道在哪里操作、输入什么、如何检查与下一步做什么。
3. 教程提供可复制或可下载的完整输入示例。示例标明虚构/演示/真实来源；无用户隐私、凭据或未授权内容。
4. 有与输入一致的示例输出及解释，说明哪些是演示数据、哪些须运行后验证、通过/失败怎样判定，不用伪造实测、排名或收益保证证明效果。
5. 用户可从任务找到适用 Skill，了解用途、安装/调用入口、必要环境/权限/费用、局限及安全边界；不适用时明确说明。
6. 用户可打开该 Skill 或工具的官方原始来源。不能以站内摘要或推介页冒充原源；引用、许可证与版本/核验日期可追溯。

## 内容与信息架构（发布阻断项）
- 教程不是目录、占位符或提示词集合；首页任务、教程、例子、Skill 卡及导航互相指向正确。
- 不把试运行规划描述成已执行测试；不宣称一定收录、一定提升排名或保证收入。
- 外链标识清楚；下载内容可正常读取；输入输出字段、数量与步骤一致。
- 用户可返回首页、查看所有任务并理解当前位置；空态/错误态提供可用出口。

## 实际站点技术验收（须运行证据）
- 路由/链接：所有公开站内导航、教程、例子、下载、Skill 原源链接检查；重要外链实际打开；不存在死链或意外跳转。未知路径返回真正 HTTP 404，并提供返回入口。
- 375px：以 375px 宽度实机或浏览器截图验证首页、教程、例子与 Skill；无整页横向溢出、遮挡或无法使用的按钮，长代码/表格可局部滚动。
- 键盘：Tab 顺序符合阅读顺序；焦点可见；菜单/交互可操作；无键盘陷阱；语义标题、链接/按钮与表单标签正确。
- SEO：每页唯一且准确的 title、description、单一主标题及 canonical；html 语言正确（英文主站为 en）；公开页可索引；不存在指向旧域名的 canonical；robots.txt 与 sitemap.xml 可访问，sitemap 只包含正式公开、200、规范 URL。
- 分享与资产：favicon、社交预览信息与站点身份一致；图片有恰当 alt；关键资产无 404。
- 来源/License：外部 Skill/代码/内容来源可追溯；转载或分发有相应许可依据及必要署名；未核实许可则仅摘要并链接，不复制分发。
- 秘密检查：源文件、构建产物、页面、下载、公开仓库变更均检查令牌、密钥、私人地址/用户资料、内部路径与内部说明；发现疑似秘密先阻断公开并报告，不在报告复述值。
- 发布边界：公开站必须是本次明确授权范围；不得通过变更现有私有站的权限、泄露登录保护内容或复用私人材料实现公开。
