# 发布前阅读检查：尚未进行真实零基础用户测试

本文件是可执行的检查方案，不是已经通过的研究报告。机器/作者能先查内容结构，真实读者是否理解仍需观察。

## 作者与实现者先检查

- 中英文首页均先出现具体人物、搜索和任务，再出现 SEO 解释。
- 两种入口都可继续学习，无站入口不跳账号注册或把无权限读报告写成失败。
- 六个旧 stage ID 各恰好一次；内容制作和发现推广职责保留。
- 理解过程六节点与实际六堂课有明确区分，没有“第3课检查抓取”等错位链接。
- 六课均有问题、解释、小动作、填好示例、完成标准、暂不用条件、有站/无站路径。
- 示例都写明是假设；不把计划功能标为已运行，不把未检查写为零。
- 搜索访问和社群访问、点击与计时完成、浏览器可开与Google可读分别解释。
- 所有任务资料可以存自己文档，无“提交产物才允许下一步”的设计。
- Skills 不抢主按钮，技术折叠默认关闭，但权限、隐私和未知项提示始终可见。
- 390px 宽视窗无横向滚动；一开始先见问题和动作，不能被六张导航卡或指标卡淹没。
- 首页、Start here 与六阶段按钮用真实路由测试；语言切换保留当前对应页。

## 对每页都问的五个问题

请一位自愿、没有 SEO 经验的人阅读，不先解释答案。每页只问以下五句，用原话记下回答：

1. 这是为谁做的？
2. 现在第一件事做什么？
3. 我需要账号吗？如果需要，是谁的网站权限？
4. 做完的东西长什么样？请指出示例。
5. 你怎么知道这一步做完了？

通过标准：无需讲解者提示，五问都能指出本页对应内容，并能开始正确的第一个动作。任何一问需要我们替他解释，就先修对应句子或布局，不用“用户太小白”解释失败。计时只作摩擦记录，不用武断秒数给读者打分。

## 两条路径各走一遍

无站路径：从首页选无网站，用文档完成第1–3课。到第4课时能说“我没有发布网站，示例也不能证明Google收录”。不注册也能到第6课，保留一份清楚标记为假设的改进记录。

有站路径：读者选择一张自己有权限、应公开的页面。能做三项浏览器检查，知道Google结论需要单独的报告。已有权限者可继续看报告，没有权限者应知道可以请管理者检查或先写未知，不应被诱导取消登录。

## 四道机制题（读完再答，不把答案放题旁）

A. 我的浏览器能打开页面，能不能写“Google已收录”？
B. 报告里有搜索点击，能不能写“这些人都完成了计时”？
C. 社群分享后来了访问，能不能写“自然搜索排名提高了”？
D. 没有网站、没有报表，我现在能做什么？

核对要点：A不能，浏览器访问和收录证据不同；B不能，需要另查实际使用；C不能，渠道不同；D能写需求、页面草图、内容和未发送计划，并用假设记录学习判断。

## 留下的测试记录

只记录实际发生的试读：日期、语言、选择路径、五问原话、第一次卡住位置、错误理解、修订、复读结果。取得对方同意，不记录不必要的身份资料。若未做，发布说明仍写“编辑审阅，未做真实零基础用户测试”。

不要求样本说“喜欢”；重点是能否解释、开始和验收。一次试读通过也不能代表所有新手或证明SEO效果。
