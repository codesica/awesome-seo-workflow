# You made a useful web page. How will people find it?

Imagine you made a free meditation timer. Someone wants to sit quietly for five minutes and searches Google for “meditation timer no download.” You want them to find your page, open it, and start the timer.

What happens in between? That is what we will learn through SEO: making your page useful and understandable, so a search engine has a chance to connect it with someone looking for it.

You do not need to know code or buy a tool. Start with one person's question.

[I do not have a website: learn with the example]
Use paper or a document to plan a page that helps someone. Later lessons use clearly fictional records. You do not need a webmaster account.

[I have a website: bring one page]
Choose a page you manage that is already intended to be public. Learn the whole process, then check your page. Keep private pages private.

## First, understand the journey from search to use

1. What are they looking for? Turn “meditation” into a specific need: a five-minute timer with no download.
2. How will this page help? Let them choose a duration and start, with short instructions nearby.
3. Can search read it? Putting a page online is not enough. Check whether the search engine can retrieve its content.
4. Has it appeared in results? A search engine saving a page does not mean it has appeared for someone's search.
5. Can visitors use it? Opening the page is a beginning. Successfully running a timer is the task this page should help them finish.
6. What should change next? Find one problem with evidence, fix it, and check again.

That is the journey through search and use. Our six practical lessons follow the work: decide whom to help → sketch the page → write and make it → check the published page → help people find a way in → check what happened and improve.

## Do this one small thing

Complete this sentence: “This page helps ____ to ____ when ____.”

Our example: “This page helps people who do not want to download an app to start a timer when they want to meditate for five minutes.”

Name a specific person and task, and you have finished your first small step. If you do not yet have a page idea, keep learning with ours.

## What will you take away?

A clear page draft and a way to tell where the process is getting stuck. Website owners can go on to collect real evidence. Learners without a site can still learn what that evidence would mean.
