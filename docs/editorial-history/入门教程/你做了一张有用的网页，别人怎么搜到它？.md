# 你做了一张有用的网页，别人怎么搜到它？

假设你做了一个免费的冥想计时网页。有人正想安静坐五分钟，在 Google 输入：“不用下载的冥想计时器”。你希望他找到这张网页，点开，就能开始计时。

中间会发生什么？这就是我们要一起学的 SEO：把网页做好、说明白，让搜索引擎有机会把它交给正在找它的人。

不需要先懂代码，也不用先买工具。我们从一个人的问题开始。

[我还没有网站：先跟着例子学]
只要一张纸或一份文档，先写出一页能帮人的内容。后面的检查用假设记录练习，不需要注册站长工具。

[我已经有网站：带一张网页来]
选一张你负责、原本就打算公开的网页。先读懂整个过程，再对照它检查。私人网页继续保持私人。

## 先理解：从一句搜索，到一次真正的使用

1. 他在找什么？先把“冥想”变成一个具体需要：不用下载，计时五分钟。
2. 这一页怎样帮到他？打开就能选时间、开始计时，旁边有简短说明。
3. 搜索能读到吗？公开上线还不够，要看搜索引擎是否能取得页面内容。
4. 结果里出现过吗？搜索引擎保存过页面，也不代表有人搜索时出现过它。
5. 点进来后用得了吗？点开网页只是开始，计时成功才是这张页面要帮人完成的事。
6. 下一次只改哪里？找到一个有证据的问题，改好，再检查。

上面讲的是搜索和使用的过程。真正动手时，我们分成六堂课：想清楚要帮谁 → 画出这一页 → 写出来、做出来 → 打开上线页面检查 → 让需要的人找到入口 → 看发生了什么，再改。

## 先做这一件小事

补完这句话：“这张网页帮助____，在____时，完成____。”

我们的填写示例：“这张网页帮助不想下载应用的人，在想冥想五分钟时，直接开始一次计时。”

写出具体的人和具体的事，就完成了第一小步。如果还没想好自己的网页，可以照着这个例子继续。

[先读入门说明：搜索怎样把问题和网页连起来]

## 你会带走什么？

一份写得明白的页面草稿，以及判断“卡在哪一步”的方法。有网站的人可以继续留下真实检查记录；没有网站的人也能学会分辨这些记录说明了什么。

这里的计时网页、人物、记录和数字都是教学假设，没有真实流量成绩。SEO 不能保证收录、排名或收入。技术部分以 Google 为例。

## 已经理解，想让 AI 帮忙？

学完某一步后，再看那一步的 Agent Skills。它们是给 AI 的任务说明，可以帮助整理和检查；你仍需要判断结果是否正确。现在不用安装任何东西。
