# Search journey illustration

Four standalone SVG assets, with Chinese and English desktop/mobile layouts. Original vector artwork; no external assets, scripts or font downloads.

Use `<picture>` with the matching mobile SVG below 640 px, desktop otherwise. Set width:100%, height:auto. Do not crop. For inline use, namespace the SVG IDs if duplicating the same asset on a page.

`nodes.json` supplies short labels and explanations. Each artwork group has `data-node-id` matching those records. Prefer a parallel HTML button list for keyboard-accessible interaction; no interactive behavior is bundled. Dashed arrows indicate possible transitions, not guaranteed outcomes.

PNG previews are review-only; deploy the SVGs.
