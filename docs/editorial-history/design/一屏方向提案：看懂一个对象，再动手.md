# 一屏方向提案：看懂一个对象，再动手

主参考：[Josh 的 SVG 教学页](https://www.joshwcomeau.com/svg/interactive-guide-to-paths/)。它把一段说明、一个演示和一组控制留在同一条阅读路径，字级不会与图中的标签打架。次参考 [Brilliant](https://brilliant.org/) 仅用于“动作与反馈一一对应”；不复制它的衬线标题、商标、角色、文案或插图。

## 先定一个构图

左：一个问题、两行解释、一个动作。右：一张假设搜索结果的剖面，搜索词与页面标题分别说明“这个人要做什么”和“这张页面能帮什么”。前后切换只改变标题，并保留原稿可见。输出只是一句改写后的标题和理由。它不证明收录、排名或真实需求。

这次没有把流程再套成一排圆圈箭头，也不复用现有 12 张 SVG。桌面与手机 SVG 都是原创静态线框，可修改；不是已完成交互网页或最终插画验收。

## 建议 tokens（全部待确认，不冒充参考 CSS 实测）

- 统一系统无衬线；英文与中文同一字体栈、相同字重规则。正文 400、标题/控件 600，仅关键处 700。SVG 标签继承网页字体。
- H1：桌面 52/62px，手机 32/42px；正文：桌面 18px，手机 16px；中文行高 1.7，英文 1.6；图中操作标签不少于 16px。
- 背景 #F8FAFC，正文 #1B2537，辅助文字 #58677C，主动作 #315ECC；图中重点使用同一蓝色，淡蓝 #EAF0FF。无需酸橙色。
- 内容最大 1120px；阅读列 680px；手机边距 20px。间距仅用 4/8/12/16/24/32/48/64/96。
- 演示圆角 16px，控件 8px；图形线宽 2px、圆端点，不随缩放变细。手机重排对象，不缩小桌面大图。
- 控件先有文字再有状态色；焦点 2px 蓝色外框，键盘 Enter/Space 可切换。reduced motion 展示静态前后状态。

## 一屏线框

`one-screen-desktop.svg/png` 是 1440×900；`one-screen-mobile.svg/png` 是 375×940，演示从 y=345 开始。只需先确认字体、留白、颜色和这一个对象构图，再制作同一视觉语言的后续机制图。
