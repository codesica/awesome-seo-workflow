# First Crawl：本轮零基础内容重写蓝图

## 本轮范围

替换现有首页核心文案、Start here 和六阶段教学层。保留既有阶段 ID、完整 SEO 职责、技术教程和 Skills。没有新产品功能、账号创建、部署、站点权限调整。本交付是内容蓝图和可接入文本，不是已上线版本。

## 问题判断

原内容不是缺少术语释义，而是先要求交付“机会卡、页面简报、内容包”，再教这些东西如何产生；一次出现的输入、动作、术语过多，读者无法决定第一步。解决方式是讲解在先、填好实例在旁、一次小动作在后，工具与完整清单按需展开。

只用一个贯穿案例：假设的免费冥想计时网页。没有真实网站、搜索需求、用户反馈或流量成绩。例子中的“免费”“不用下载”等是拟定能力；第 3 课明确其尚未实现测试，不能复制为真实产品承诺。

## 首页信息顺序

1. 一个具体场景：有人搜“不用下载的冥想计时器”，希望立即计时。
2. 一句话解释 SEO 的帮助与边界。
3. 两条入口：还没有网站／已有网站。不是六张先决条件卡。
4. 六节点理解示意：用户问题 → 有用页面 → 搜索能读到 → 搜索结果出现 → 点击和使用 → 改进。
5. 明确说明：这条示意解释发生过程，不是课程阶段；下方用一行给出实际六堂课。
6. 只有一次填空练习和一份完成示例；主按钮进 Start here。
7. 简短预期结果与假设标签。
8. Skills 介绍移到学习后的辅助位置。首屏不出现安装命令、技术术语墙或指标卡。

## 六阶段一对一映射（不改 ID，不偷换职责）

- 01-search-opportunity：需求与搜索机会 → 想清楚要帮谁。留下四行问题说明，再看一条非广告结果。完整研究是可继续做的深层内容。
- 02-page-plan：页面方案 → 画出这一页。留下三框草图；有站者判断新建还是更新，无站者地址写“还没有”。
- 03-content-production：内容制作 → 写出来、做出来。留下标题和三句说明、事实与功能待查项。草稿和真正运行的工具明确分开。
- 04-publish-check：发布与技术检查 → 打开上线页面检查。先做三项普通访客检查，再分开记录 Google 证据。原抓取、sitemap、单页检查教程留在此阶段。
- 05-discovery-promotion：发现与推广 → 让需要的人找到入口。站内入口与站外相关分享计划都保留；已改页/已发送/只拟稿严格分开。
- 06-measure-iterate：数据与迭代 → 看发生了什么，再改。四行观察记录，保留真实报告入口与同口径比较；无数据走纸上练习/真实反馈，不造报表。

## 每页固定阅读顺序

一个普通人的问题 → 一段解释和贯穿例子 → 一次具体动作 → 填好样例 → 有站/无站任务分支 → 完成标准 → 何时暂不用 → 折叠细节 → 可选 Skills → 下一课。

“首屏”指阅读优先级，不要求把六个大块挤在一个视窗。手机上最先看到问题、解释和一个动作即可。已读折叠状态不应由新手必须展开才能完成基础练习；权限和隐私提醒不能只藏在折叠里。

## 无站者完整路径

前 3 课在自己的文档完成；不上传，不注册。第 4 课先读假设检查记录；如需真实浏览，用第 1 课找到的公开页面，只做无需注册付款的普通使用检查，没有其后台权限就不访问后台。必须说明“公开页练习不等于已发布自己的站”。第 5 课做未发送入口计划，第 6 课做标为假设的文案改进或实际发生的试读记录。

站点拥有者只有到第 4/6 课才见 Search Console，首次解释“Google 免费站长工具，需要对应网站权限”。访问不了报告就记未检查；不是重新注册即能读所有网站。私密网页不要求变公开。

## 原内容处置

保留原技术准确性和官方来源。把 robots、noindex、canonical、sitemap、hreflang 等从全员先修词表移到第 4 课维护者/专项折叠区；这些旧教程不能突然出现在第 3 课。把关键词估算、多选题研究移到第 1 课“想继续研究”；不再是完成第一练习的条件。把完整内容核验记录放在第 3 课进阶层。第 5 课推广不删除，保留入口和分享权限边界。第 6 课高级指标留在数据层，不用平均排名教育第一次访问者。

概念库继续作为查阅资源，不是先读完才能上课的门槛。现存概念库有图片压缩等其他例子；新手路径首次链接时，优先让用户停留本课同主题说明。若同步重写概念例子，应只替换为同一计时情境，不新增术语。

## 集成约束

stages.replacement.json 是新教学层的内容数据，不是旧 workflow schema 的直接覆盖文件。其每条 id 与原阶段一致。把 firstScreen/task 等明确接到页面；旧 actions 可作为“完整流程”折叠内容，不能同时展开形成双份任务。首页与 Start here 文本中的方括号是按钮标签，不是已存在网址；集成人员用当前实际路由绑定。已有阶段路由保持不变。

需将 Start here 加入现有学习入口，但不需要新增交互功能。四份 Markdown 是全部核心正文；若站点既有 Start here 路由，替换正文即可。技术来源可复用既有来源页，并补本轮核对记录。
