## Evidence labels

- PUBLIC_SOURCE_CHECKED: the linked definition or rule was read on the stated date; verify again when policies or tools change.
- PROPOSED: the teaching action or editorial decision is a design recommendation, not a claim that an official source mandates every field.
- SYNTHETIC: a wholly invented product, response fixture or arithmetic example. SpokeNote and the named alternatives are not real test subjects; example.com is reserved illustration text, not an active demo link.
- NOT_RUN: no corresponding execution occurred. UNKNOWN: the answer or effect is not established. An observed zero must come from an actual defined measurement.

CSV files contain field headers only. Fill them with project-specific conditions; no preset threshold, result, account or identifier is implied. The field names are shared across languages; both module texts explain their use.

## Publication boundary

Only original teaching text, independently invented examples, blank templates, and public-source metadata are included. There are no real account exports, screenshots, personal data, private source links or transplanted experiment records. This package is candidate copy for review, not an independently deployed release. It introduces no third-party skill code; the external documents remain with their publishers and are linked for attribution.

A source supports only the stated scope. Rules do not prove demand. A plausible method does not prove efficiency. Source verification, functioning implementation, reader comprehension and SEO/business results need separate evidence.
