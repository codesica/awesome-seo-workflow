# 让一个页面有资格拥有独立 URL

公开来源核对日期：2026-10-10。本文是待执行的教学作业，不是已完成审计或效果证明。示例完全虚构。

## 要做的决定

这页帮助读者完成什么，又比现有答案增加什么？先完成一份页面简报，再考虑关键词页面规模。模板属于实现选择，页数不是价值指标。

## 输入

一张机会卡、明确的读者任务、少量现有替代方案，以及事实来源。写清现在能展示什么；拟做功能不能标为已实测。

## 操作

1. 以读者结果定义完成：能用的答案、能辅助选择的比较，或有效输出。选择一种具体贡献：原创分析、透明比较、直接经验、有来源的数据或可运行工具。Google 要求检查相较复述来源的增量价值，Bing 要求内容清楚并满足意图。（S04、S05）
2. 先写首屏：具体任务的标题、尽早出现的答案及相关下一步。标题、正文、功能兑现同一承诺。各页元数据准确且有区别；标题或描述的字数不是通用判错线，搜索引擎可能选择不同展示文字。（S25、S26）
3. 建主张账本：主张、来源、核对日期、实测范围与限制。比较说明方法；没有对应证据时，不贴“实测”“最佳”“最快”“专家审核”或“用户验证”。
4. 对页面家族写每页差异：任务、来源数据、计算或输出哪里不同。删除变体名称后还剩什么？这是编辑启发式，不是官方排名测试。只换名词时，合并答案或在同一页面处理。以操纵排名为目的、缺少用户价值的规模化发布可能违反 Google 政策。（S06）
5. 具备自愿参与与访问条件后，请未参与创作的目标读者独立完成任务，记录实际操作、卡点与输出可用性。执行前理解验证保持 NOT_RUN，清单不能替代观察。
6. 只修改证据指向的最小部分。一个人误解一句指令，不证明整个市场、品牌或主题错误。保留旧版本，解释变化。

## 虚构输出示范

这一独立模拟简报探索 SpokeNote 的雨天通勤清单；没有新的真实证据时，它并不推翻前一个 NO_GO。页面拟让读者编辑并打印清单，拟标题为“制作可打印的雨天通勤装包清单”，附可编辑示范、纯文本替代与不覆盖范围。不声称避免事故、判定器材适配或已有搜索需求。“周末清单”若只换标题，不另建 URL。

## 交付与证据

交付页面简报、主张账本、一个拟定 URL、增量贡献与完成定义；功能检查、读者观察有执行才附。模拟输出标 SYNTHETIC，未实现功能标 PROPOSED。

编辑验收是标题、答案与输出服务同一任务，主张可追溯。功能就绪、读者理解、索引与效果分别验收。

## 失败边界

固定字数与页数不能保证质量。E-E-A-T 本身不是具体排名因子，不造分数。精美草稿不证明排名、收入或 AI 引用；不要编造经历、评价、审核或日期。

## 有界 Agent 任务

“按机会卡写一份任务驱动页面简报，明确增量价值、事实来源、承诺输出、变体合并，以及尚待检查项。没有提供证据时，功能、示例和读者测试一律不算已经执行。”
