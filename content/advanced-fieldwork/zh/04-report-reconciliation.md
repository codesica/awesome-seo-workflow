# 先对齐口径，再解释搜索报表

公开来源核对日期：2026-10-10。本文是待执行的教学作业，不是已完成审计或效果证明。示例完全虚构。

## 要做的决定

变化是否发生在可比较口径内，下一步该检查哪一层？报表有遗漏与聚合规则，仅靠变化不能诊断需求、产品质量或算法更新。

## 输入

站主提供的导出，或明确标注的合成练习表。记录 property、日期、source/搜索类型、国家、设备、query/page 筛选、维度、聚合方式、报表时区与导出时间。无需新账户或新埋点。

## 操作

1. 看数字前保存口径头，使用相同设置下的完整窗口比较，标注暂定或未完整周期。GSC 常规日数据按 Pacific Time，24 小时视图按浏览器本地时间；滚动视图不能直接称“昨天”。（S03）
2. 分开图表总计与查询表。匿名查询可能计入无查询筛选的总计，但不显示在查询表；加 query 筛选会排除它们，表格还可能截断。行之和或“包含／不包含”筛选之和不必等于总计，不能把全部差额指定给一个原因。（S14）
3. property 与 page 聚合分别记；同一次结果出现多个本站页面，计数方式可能不同。Google 的很多表现归到引擎所选 canonical，重复地址显示零不等于没人落地。（S14）
4. CTR 只用同口径点击÷曝光；总 CTR 不等于各行 CTR 的简单平均。平均位置按相关最高位置跨曝光聚合，不是固定关键词排名，也不能直接平均表中平均值。（S15）
5. Bing 先固定 Source。All 合并多个展示来源，而 Keywords、Pages 与平均位置只针对 Web，比较关键词行前先改为 Web 口径。不照搬 Google 聚合规则；历史范围以实际日期选项为准，不硬编码可能滞后的帮助页月份。（S16）
6. 在一致口径内按查询、页面、设备或国家下钻，写“观察＋替代解释＋下一项有界验证”。获客与成功任务分开，点击不能证明用户完成任务。

## 虚构算术示范

模拟表有未筛选点击 87，“包含”筛选 24，“不包含”筛选 38。仅凭这些数不能说差额 25 全来自匿名查询。另一道 CTR 练习为 3 次点击／60 曝光与 9／300，合计应为 12／360＝3.33%，不是简单平均 4%。这些是独立虚构算术，不是真实账户导出。

## 交付与证据

交付口径表、同口径前后对照、尚未解释的差额及一个下一问题。账号原始导出留在私有证据，公开教材只用声明过的合成表。数据缺失写 UNKNOWN，确实观察到零才写 0。

完成意味着单位、分母、周期与聚合方式可复核，不意味着根因已找到。

## 失败边界

没有独立证据，不能把短期变化归给算法。两个系统的覆盖与群组不兼容时，不能拿一方任务完成除以另一方点击。边缘请求、IP、被测会话与人是不同单位，本作业无需推断身份关联。

## 有界 Agent 任务

“检查提供报表的范围与计算，分开缺失行、筛选和聚合影响，只计算可比率。输出观察、可能解释、未知与最小下一检查，不推断用户身份或因果增长结论。”
