# Beginner teaching layer

This layer supplies the Chinese and English homepage, introduction, six practical lessons, and lesson route. It uses one explicitly fictional free five-minute meditation timer story. Its planned interface, observations, and records are teaching examples, not a working timer, demand research, traffic data, or user-test results.

The introduction is separate from lesson 1. Both use the same four-line record: whom the page helps, the task, possible help, and unknowns. Lesson 1 reuses that record; a real search is optional. Lessons retain both paper-only and existing-site paths, completion criteria, and honest unknowns.

The original six stable stage IDs and all 25 actions remain available inside the collapsed complete checklist. The three full technical tutorials, four synthetic fixtures, actual local CLI evidence, 23 concept entries, six blank templates, seven original execution Skills, and three third-party source pages remain available at their existing bilingual routes. Their evidence and execution boundaries are preserved. Existing deep links expand containing details without losing their target.

## Editorial review, 10 October 2026

The uniform bilingual teaching draft was reviewed in the existing signed-in **Gemini consumer web app at gemini.google.com**, using the mode displayed as **Flash**. Two prompts were submitted and both responses were read. The web interface did not expose an exact model version. This was text editing and editorial review, not a real beginner usability test.

Human review rejected the first draft's suggestion that people would automatically find the page, and restored promotion as a separate responsibility. The second response's eight suggested corrections informed clearer entry labels, a consistent four-line exercise, an explanation of result appearances, matching lesson-1 instructions, explicit unbuilt feature labels, draft-versus-working-tool boundaries, discovery-versus-indexing distinctions, and concrete observation examples. Search-report impressions are described under their counting rules rather than equated with every ordinary visual appearance.

Human review also made searches optional, adapted lesson 3 to the owner's actual task rather than requiring every site to run a timer, and added a paper-only completion criterion to lesson 6.

No account purchase, subscription upgrade, permissions change, key change, or API generation was needed for this consumer-web review. Only public site copy and teaching requirements were submitted.

## Limits

The paper path teaches planning and evidence interpretation; it does not build or deploy the timer. Real Google account reports require the owner's existing site permissions. Reading checks and browser QA do not establish that a real beginner understood the lessons, nor do they establish indexing, rankings, traffic, or growth. Keep these questions separate in later validation.
